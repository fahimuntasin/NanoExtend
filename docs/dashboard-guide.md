# Dashboard Guide

- **Home:** STA/AP status, NAT, health, heap, uptime, reconnects.
- **Scan:** asynchronous Wi-Fi results cached for 15 seconds.
- **Clients:** connected SoftAP stations.
- **Settings:** AP identity, hostname, secure backup/restore.
- **System:** firmware/SDK, flash, reset and crash diagnostics.
- **OTA:** SHA-256 verified local updates and progress.
- **Logs:** bounded 200-entry redacted RAM log and export.

The dashboard is embedded as gzipped PROGMEM assets and has no external runtime dependency.
