# Support

## Start here

1. Read [Troubleshooting](docs/troubleshooting.md) and [FAQ](docs/faq.md).
2. Search GitHub Discussions for setup questions.
3. Search existing issues for confirmed defects.

## Where to ask

- **Discussions:** installation help, ideas, hardware compatibility, and usage questions.
- **Issues:** reproducible bugs in supported hardware/software.
- **Private security reporting:** vulnerabilities and sensitive disclosures.

Include the NanoExtend version, board revision, flash size, serial logs with secrets removed, expected behavior, and exact reproduction steps.
