# NanoExtend Brand

NanoExtend’s identity is original and built around a compact routed “N” with
two circuit nodes and outbound radio waves.

## Assets

- `logo.svg` — primary square mark and favicon source
- `banner.svg` — README/GitHub/social banner (1200×630)
- Website `Logo.tsx` — accessible inline version with optional animation

## Color system

| Token | Value | Use |
|---|---|---|
| Ink | `#050505` | Primary background |
| Panel | `#0A0A0A` | Cards and surfaces |
| Line | `#1D1D1D` | Borders and separators |
| Muted | `#8B8B8B` | Secondary text |
| Signal | `#F7F7F7` | Primary text and active state |

The public identity is intentionally monochrome. Status differences must never
depend on color alone.

## Typography

Inter Variable is used by the website and may be embedded locally. System UI
fonts are the fallback. Monospace metadata uses the platform UI monospace stack.

## Motion

The animated mark draws the routed “N”, blinks a circuit trace, breathes a soft
signal aura, pulses three Wi-Fi arcs, and illuminates circuit nodes. Motion
respects `prefers-reduced-motion`.

## Usage

- Keep clear space equal to one node diameter around the mark.
- Do not recolor, skew, add gradients, or place the mark on busy imagery.
- Do not recreate or imitate another project’s brand system.
- Use `logo.svg` as the canonical source; rasterize only for platforms that
  cannot render SVG.
