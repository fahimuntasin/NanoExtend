# NanoExtend Roadmap

The roadmap is directional, not a delivery promise. Reliability and simplicity can move work between releases.

## v1.0 — Reliable foundation

- [x] SoftAP + STA and lwIP NAPT
- [x] DHCP, DNS, captive portal
- [x] Realtime dashboard and local OTA
- [x] Reconnect, health checks, logs, diagnostics
- [x] Browser installer and release automation

## v1.1 — Trusted updates and observability

- [ ] Signed release manifest and firmware authenticity validation
- [ ] Device-side GitHub/custom update manifest client
- [ ] Bandwidth counters with bounded overhead
- [ ] Expanded hardware soak-test matrix
- [ ] Internationalized dashboard foundations

## v1.2 — Developer platform

- [ ] Typed client SDK generated from OpenAPI
- [ ] Reproducible simulation/testing harness
- [ ] Additional classic ESP32 board profiles
- [ ] Pluggable captive portal themes

## v2.0 — Carefully evaluated expansion

- [ ] Secure Boot/Flash Encryption production provisioning guide
- [ ] Optional multi-uplink policies
- [ ] Mesh/repeater research without compromising base reliability
